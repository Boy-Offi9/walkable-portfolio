# Assets

Put your own files here and reference them from `src/config/site.js` without a leading slash.

- `projects/`: project screenshots, 1280x800 or similar landscape images
- `textures/`: floor, wall and desk texture sets (`npm run textures` fills this)
- `models/`: optional `.glb` models
- `hdri/`: optional equirectangular `.hdr` environment map

Example: `image: "assets/projects/orbit.png"`
